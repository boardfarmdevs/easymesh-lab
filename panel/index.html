What this measures

Download is host → client; upload is client → host. Each uses two HTTP transfers in parallel for about six seconds, capped at 128 MiB per direction. Latency is the median of five local HTTP requests. Results include browser overhead, Wi-Fi, the extender, Ethernet and USB; they are not PHY rates or an internet speed test. USB link speed, host CPU and the client can also limit throughput; consult the host measurements rather than treating this as a radio-only test.

THE BIG PICTURE

A controller asks.
An agent reports and configures.

IEEE 1905.1 carries control messages directly over Ethernet. Multi-AP TLVs add radios, clients, metrics and steering. IP, DNS and internet access are not prerequisites for this lab exchange.

→→
01

Anatomy of a message

Ethernet 14 bytesCMDU header 8 bytesTLV list variableEOM 3 bytes

EtherType 0x893a identifies 1905. The CMDU header identifies the message, transaction ID, fragmentation and relay flags.

Each TLV is Type (1 byte) + Length (2 bytes) + Value. Length counts value bytes, excluding the three-byte TLV header. The zero-length End of Message TLV ends the list.

02

What does “success” mean?

  • Sent: the host transmitted a frame.
  • ACK: the agent acknowledged receipt.
  • Response: inspect result codes and error TLVs.
  • Outcome: observe the SSID, channel or client association changing.

A steering request cannot guarantee a client roams. Client capabilities, target coverage, agent policy and timing all matter.

03

Learn through three experiments

  1. Read topology, then identify the AL MAC, radio IDs and BSSIDs.
  2. Read AP metrics. Compare channel utilization before and during client traffic.
  3. With a client connected, request link metrics and then a beacon report. Compare AP-side and client-side measurements.
04

Know the boundaries

The verified onboarding path is WPA2 on 2.4/5 GHz. An experimental 6 GHz WPA3-SAE path is now implemented, but this agent has not yet provided its 6 GHz M1. Requested, M2 sent and operational BSS confirmed are separate states.

Raw composition exposes additional message types, but it does not implement their state machines. Unknown TLVs stay visible as raw bytes.
